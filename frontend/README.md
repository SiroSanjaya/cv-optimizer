# CV Optimizer frontend

React, Vite, TypeScript, and Tailwind frontend for CV Optimizer.

## Development

```bash
npm ci
cp .env.example .env
npm run dev
```

The API URL is configured with `VITE_API_URL`. See the repository
[README](../README.md) for full setup, API, privacy, and deployment information.

## Quality checks

```bash
npm run lint
npm run build
```
