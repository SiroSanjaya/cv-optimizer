CV Optimizer

Asisten apply lokal untuk Greenhouse dan Lever.

Extension mengisi field yang dikenali dan dapat melampirkan CV PDF. Periksa data, lengkapi pertanyaan yang belum didukung, lalu tekan tombol submit di situs ATS sendiri.

Belum ada paket lamaran.

Hanya mengisi informasi kontak, cover letter, dan lampiran CV yang dikenali. Tidak mengirim formulir, menjawab screening, memilih izin kerja/EEO, atau melewati CAPTCHA. Paket berisi data pribadi—jangan bagikan file JSON ke orang lain.
